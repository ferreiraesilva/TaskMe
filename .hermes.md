# TaskMe — Hermes Plugin Context

## O que é este projeto
Plugin Hermes para atribuição e follow-up de tarefas via WhatsApp.  
Qualquer usuário autorizado fala com o Hermes (texto ou áudio), atribui tarefas a colegas, e o sistema cobra e acompanha até conclusão.

## Estrutura
- `plugin.yaml` + `__init__.py` + `schemas.py` + `tools.py` + `hook.py` — plugin Hermes
- `taskme/` — lógica determinística (serviços, templates, datas PT-BR, notify)
- `migrations/0001_init.sql` — schema Postgres idempotente
- `cron/` — scripts para os 3 jobs agendados
- `tests/` — pytest (33+ testes, sem banco)

## Ferramentas registradas (taskme_*)
| Ferramenta | Quando o Hermes usa |
|---|---|
| `taskme_propor_tarefa` | Usuário quer atribuir tarefa → propõe sem gravar, aguarda confirmação |
| `taskme_criar_tarefa` | Após "sim" do usuário → grava e envia ao destinatário |
| `taskme_add_contato` | Contato não encontrado → salva telefone e reusa |
| `taskme_consultar` | "minhas pendentes", "o que pedi pra X", "atrasadas" |
| `taskme_detalhe` | "por que a TM-XXXX foi reprogramada" |
| `taskme_reprogramar` | Assignante quer mover prazo |
| `taskme_concluir` | Assignante confirma entrega fora do fluxo de cobrança |
| `taskme_responder` | Fallback para ÁUDIO de cobrança (texto é roteado pelo hook) |

## Hook pre_gateway_dispatch
Intercepta respostas de texto a cobranças antes do LLM:
- Remetente com cobrança aberta + texto → parse determinístico → `handle_reply` → skip
- Remetente com cobrança aberta + áudio → allow → agent transcribe → `taskme_responder`
- Qualquer outro → allow

## Cron jobs (criar uma vez)
```bash
hermes cron create "0 0 * * 1" --no-agent --script ~/projects/TaskMe/cron/monday.sh --name taskme-digest-segunda
hermes cron create "1 0 * * *" --no-agent --script ~/projects/TaskMe/cron/diario.sh --name taskme-digest-diario
hermes cron create "2 0 * * *" --no-agent --script ~/projects/TaskMe/cron/cobrancas.sh --name taskme-cobrancas
```
