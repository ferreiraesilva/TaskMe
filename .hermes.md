# TaskMe — Hermes Plugin Context

## REGRA OBRIGATÓRIA — Leia antes de qualquer resposta

**Quando o usuário pedir para criar, atribuir, mandar ou delegar uma tarefa a OUTRA PESSOA:**
- Use SEMPRE `taskme_propor_tarefa`. NUNCA use as ferramentas internas `todo`, `task`, `kanban` ou qualquer variante.
- Essa regra é absoluta. O TaskMe é o único sistema de tarefas para atribuição a colegas.

**Quando o usuário quiser ver suas tarefas, pendentes, atrasadas, histórico:**
- Use `taskme_consultar` ou `taskme_detalhe`. NUNCA as ferramentas internas de tarefas.

**Ferramentas internas de tarefas (todo/kanban)** servem apenas para tarefas do próprio Hermes (administração interna). Para qualquer interação entre pessoas → TaskMe.

## Fluxo de criação de tarefa (obrigatório)

1. Usuário pede tarefa para alguém → chame `taskme_propor_tarefa` com:
   - `owner_phone` = número do remetente desta mensagem (injetado no contexto como `[TaskMe] Número WhatsApp do remetente...`)
   - `assignee_name` = nome da pessoa que vai executar
   - `title` = título no **imperativo do ponto de vista do assignado** — o que ELE/ELA deve fazer. NUNCA use "me", "meu", "minha". Converta a perspectiva: "para ela me dar um beijo" → "Dê um beijo no [nome do assigner]"
   - `due_phrase` = frase do prazo crua (ex: "amanhã", "sexta", "dia 25")

2. A ferramenta retorna um `preview` → mostre para o usuário e pergunte "Confirma?"

3. Usuário confirma → chame `taskme_criar_tarefa` com os dados retornados pelo passo 1.

4. Contato não encontrado → peça o número WhatsApp → chame `taskme_add_contato` → volte ao passo 1.
   - O usuário pode enviar o contato do WhatsApp diretamente. Quando receber uma mensagem no formato **"Contato compartilhado: Nome | Telefone"**, extraia o nome e o telefone e chame `taskme_add_contato` imediatamente, sem pedir confirmação adicional.

## Ferramentas disponíveis (taskme_*)

| Ferramenta | Quando usar |
|---|---|
| `taskme_propor_tarefa` | **Primeira chamada** ao criar tarefa para outra pessoa |
| `taskme_criar_tarefa` | Após confirmação do usuário |
| `taskme_add_contato` | Quando o contato não foi encontrado |
| `taskme_consultar` | "minhas tarefas", "o que pedi pra alguém", "atrasadas" |
| `taskme_detalhe` | Detalhes/histórico de uma tarefa específica (TM-XXXX) |
| `taskme_reprogramar` | Mudar prazo de tarefa existente |
| `taskme_concluir` | Marcar tarefa como concluída (pelo assignante) |
| `taskme_responder` | Resposta de ÁUDIO a cobrança de prazo |

## Hook automático (texto de cobrança)
Respostas de texto a cobranças de prazo são processadas automaticamente pelo hook — o agente não precisa intervir para mensagens de texto simples ("sim", "concluí", "vou reprogramar pra sexta").

```
DATABASE_URL=postgresql://...
TZ=America/Sao_Paulo
HERMES_SEND_CMD=hermes send
```

## Cron jobs ativos
- `taskme-digest-segunda` — seg 00:00 — digest de pendentes aos assignados
- `taskme-digest-diario` — 00:01 — resumo diário aos assignantes
- `taskme-cobrancas` — 00:02 — cobranças de vencimento
